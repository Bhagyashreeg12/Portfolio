## 🚀 About the Portfolio
A modern, responsive, glassmorphic portfolio website showcasing real-world machine learning models, spatial-temporal time series forecasts, and production-grade MIS automation pipelines.

### 🎯 Key Interactive Features
- **Live Decision Threshold Optimizer**: An interactive widget allowing visitors to adjust machine learning classification thresholds ($P_{cut}$) in real time to observe Precision vs. Recall business trade-offs.
- **Deep-Dive Case Studies**: Interactive modals detailing problem statements, architectures, and real evaluation plots (ROC-AUC, PR-AUC, confusion matrices, PCA cluster maps).
- **Dynamic Theme Switcher**: Modern Dark Theme (default) and Light Theme with persistent local storage.
- **Categorized Project Filtering**: Filter by *Machine Learning*, *Data Analytics & BI*, *Automation & MIS*, and *Time Series*.

## 📂 Featured Case Studies Included

1. **BranchPulse — Insurance MIS Automation System**
   - *Tech:* Python, SQLite, Openpyxl, Dynamic Excel Formulas (`SUMIFS`, `VLOOKUP`, `INDEX/MATCH`), HTML Digest.
   - *Highlights:* Automated 12 branches, engineered automated quality gate handling 76 audit anomalies, 100% reconciliation pass.
   - *Repo:* [BranchPulse-MIS](https://github.com/bhagyashreeghosh004-hub/BranchPluse-MIS)

2. **Credit Card Fraud Detection ML Pipeline**
   - *Tech:* Python, Scikit-Learn, Random Forest, Gradient Boosting, SMOTE, Threshold Tuning.
   - *Highlights:* 85% fraud recall, 89% precision, 0.81 PR-AUC on 1.5% imbalanced distribution with only 0.16% false alarm rate.
   - *Repo:* [Fraud_Detection_System](https://github.com/bhagyashreeghosh004-hub/Fraud_Detection_System)

3. **Customer Segmentation & RFM Behavioral Analytics**
   - *Tech:* Python, K-Means Clustering, PCA Dimensionality Reduction, Hierarchical Dendrograms, Seaborn.
   - *Highlights:* 4 actionable customer personas with 0.62 silhouette score to guide targeted marketing retention.
   - *Repo:* [Customer_Segmentation](https://github.com/bhagyashreeghosh004-hub/Customer_Segmentation)

4. **EV Charging Demand Forecasting (Hybrid Deep Learning & ML)**
   - *Tech:* Python, SARIMA, LSTM, Random Forest, XGBoost, Temporal Lag Engineering.
   - *Highlights:* Spatial-temporal forecast across 4 operational grid zones using 365 days of sensor logs.

5. **Chicago Crime Rate Prediction & Power BI Spatial Analytics**
   - *Tech:* Power BI, DAX, Tableau, Python, Geospatial Mapping.
   - *Highlights:* Citywide incident trends from 2001 to present, predictive hotspot modeling for proactive patrol allocation.

6. **Heart Disease Clinical Risk Scoring**
   - *Tech:* Python, Logistic Regression (LBFGS), CDC BRFSS Dataset (319,795 records).
   - *Highlights:* Clinical odds-ratio feature analysis identifying key cardiovascular risk drivers.
